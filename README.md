## Про семафоры

- **Координатор** — родительский процесс: составляет пары, считает очки, печатает таблицу.
- **Студент** — дочерний процесс (через fork), выбирает жест и сообщает координатору.

Общие данные лежат в разделяемой памяти POSIX. Синхронизация — через неименованные POSIX-семафоры, которые тоже лежат в разделяемой памяти.

---
## Параметры запуска

```
./tournament [N seed strategy par delay tie_rule]
```

| Параметр   | По умолчанию | Что значит                                                  |
| ---------- | ------------ | ----------------------------------------------------------- |
| N        | 4          | число студентов (2…100)                                     |
| seed     | 42         | начальное значение ГСЧ                                      |
| strategy | 0          | 0 — случайно, 1 — по циклу, 2 — фиксированно          |
| par      | 1          | сколько партий идёт одновременно                            |
| delay    | 0          | пауза перед ходом, сек                                      |
| tie_rule | 0          | 0 — общее место при равных очках, 1 — строго по порядку |

---
## Что гарантируется

1. Каждая пара играет ровно один раз.
2. Студент не играет две партии одновременно.
3. Жест фиксируется до раскрытия (координатор ждёт ready от обоих).
4. За победу — 2 очка, за ничью — 1, за поражение — 0.
5. Результат партии учитывается один раз.

---
## Завершение

- **Обычное:** после `N(N−1)/2` партий печатается итоговый рейтинг.
- **По `Ctrl+C`:** обработчик ставит флаг, координатор будит детей и корректно завершает их.

В обоих случаях удаляются семафоры
