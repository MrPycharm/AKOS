## 1. Условие задачи

Несколько студентов проводят **однокруговой турнир** в игру "Камень, ножницы, бумага". Каждый участник встречается с каждым другим ровно один раз. Для каждой партии оба игрока независимо выбирают один из трёх жестов, после чего результат раскрывается одновременно.

За победу начисляются **2 очка**, за ничью - **1 очко**, за поражение - **0 очков**. Партии могут проводиться последовательно (при последовательной программе) либо параллельно при условии, что один студент не участвует одновременно более чем в одной партии. Координатор турнира формирует таблицы результатов.

Требуется разработать **консольное приложение**, моделирующее турнир.

| Параметр                                      | Описание                   | Способ задания                           |

| Количество студентов                          | `N`, должно быть >= 2      | Аргумент командной строки / интерактивно |
| Начальное значение генератора случайных чисел | seed для воспроизводимости | Аргумент командной строки                |

---
## 3. Отображаемые события

Программа должна выводить в терминал:

- формирование пары
- готовность игроков
- одновременное раскрытие жестов
- результат партии
- начисление очков
- текущую таблицу
- итоговую таблицу
---
## 4. Инварианты

1. Каждая неупорядоченная пара играет **ровно один раз**.
2. Участник **не играет одновременно** в двух партиях.
3. Жест игрока **фиксируется до раскрытия** жеста соперника.
4. За партию начисляется **установленная сумма очков** (2 + 0, 1 + 1 или 0 + 2).
5. Результат партии учитывается в таблице **один раз**.
---
## 5. Условие завершения

Программа завершается после проведения $\frac{N(N-1)}{2}$ партий и построения итогового рейтинга.

## 6. Блоки работы программы и основные детали

## 7. Пользовательский интерфейс

### Запуск

```bash
./tournament [N] [seed] [delay]
```

- `N` - количество студентов (по умолчанию 2);
- `seed` - начальное значение сида (по умолчанию 42);
- `delay` - задержка в секундах между событиями (по умолчанию 0).

Участников: 4 | Seed: 1234 | Задержка: 1 сек
