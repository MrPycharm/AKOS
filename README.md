## Входные параметры

Позиционные аргументы командной строки; без аргументов — значения по умолчанию.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `N` (студенты) | `4` | от 2 до 100 |
| `seed` | `42` | начальное значение ГСЧ (`rand_r`, своё состояние у каждого) |
| `strategy` | `0` | `0` — случайно, `1` — по циклу, `2` — фиксированно по `id` |
| `par` | `1` | число одновременных партий (1 … N/2) |
| `delay` | `0` | пауза перед фиксацией жеста, сек (0 … 3600) |
| `tie_rule` | `0` | `0` — общее место, `1` — места строго по ID |

---

## Инварианты

1. Каждая неупорядоченная пара играет **ровно один раз** — контролируется матрицей `played[MAXS][MAXS]`.
2. Участник **не играет одновременно** в двух партиях — координатор при наборе партии помечает занятых в массиве `busy`.
3. Жест игрока **фиксируется до раскрытия** — поток студента пишет в `gesture`, затем делает `sem_post(&ready)`; координатор ждёт `2 * cnt` сигналов, и только после этого раскрывает жесты.
4. За партию начисляется **установленная сумма очков** (2 + 0, 1 + 1 или 0 + 2).
5. Результат партии учитывается в таблице **один раз** — раскрытие и подсчёт идут после полного «сбора» жестов всех запущенных в раунде пар.

---

## Условие завершения

После `N(N−1)/2` партий и построения итогового рейтинга координатор выставляет всем `stop = 1`, делает `sem_post(&start)` для каждого потока и дожидается `pthread_join`.
